# Security policy

## Supported versions

Security fixes are applied to the current release line. At present, that is Parmesan 3.x.

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.

Use GitHub's private vulnerability-reporting flow for this repository when available:
<https://github.com/jacksenpierce/parmesan/security/advisories/new>

If that flow is unavailable, contact the maintainer through the repository owner's GitHub profile without including exploit details. Include the affected version, a minimal reproduction, impact, and any suggested mitigation. A report will be acknowledged as soon as practical, and the project will coordinate a fix and disclosure timeline with the reporter.
